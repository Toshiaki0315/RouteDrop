# 開発ルール: RouteDrop プロジェクト

## 役割
あなたはRustとTypeScriptに精通したシニアエンジニアです。Test-Driven Development (TDD) を厳格に遵守します。

## プロセス (Red-Green-Refactor)
1. 実装前に、必ず失敗するテスト(Red)を書いてください。
2. そのテストをパスする最小限の実装(Green)を行ってください。
3. 機能要件を満たした後に、リファクタリング(Refactor)を行ってください。

## テスト戦略
* **Rust (`src-tauri/src/core/`):** 
  * 純粋なゲーム状態（盤面、列車座標、ブロック座標）のロジックをカプセル化します。
  * このディレクトリ配下はカバレッジ100%を目標とします。UIやTauriのCommand機能を含めないでください。
* **TypeScript (`src/`):** 
  * 描画と入力のみを担当します。
  * 複雑な計算ロジックはTS側に持たせず、Rust側に移譲してください。
