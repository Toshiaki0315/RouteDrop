# RouteDrop

落ちゲー × オートマトン。落ちてくるパネル（直進 / 右折 / 左折）を積んでロボットの進路を作り、ゴールへ導くパズルゲーム。Tauri v2 (Rust + React/TypeScript) 製の macOS デスクトップアプリ。

## ルール

- 盤面は 7×12 の草地。**スタート駅は盤面の下、ゴール駅は盤面の上**（どちらも中央・盤面の外）にある。
- 落下するのはレール。種類は直進・右折・左折の 3 つでランダム、出現する列もランダム。次に降るレールは左上の「NEXT」に表示される。
- レールは 2 つの端をつなぐ。Space で時計回りに 90° 回せる。
  - 向きが北のとき、直進は 南↔北、右折は 南↔東、左折は 南↔西 をつなぐ。
- 機関車 (SL) は 0.5 秒ごとに正面へ 1 マス進む。
  - 正面が **レール**: つながっている端から入って、反対の端へ抜ける（逆向きからも通れるが、引き返すことはできない）。
  - 正面が **つながっていない辺のレール**: 脱線してゲームオーバー。
  - 正面が **空きマス**: その場で待機する。
  - 正面が **ゴール駅**: クリア。
  - 正面が **盤面の外（ゴール以外）・壁**: ゲームオーバー。
- 落下パネルは 1 秒ごとに 1 マス落ち、着地するとレールとして盤面に固定される。
- **ライン消去**: 機関車より下（通過済み）の行がすべてレールで埋まると、その行が消えて +50 点。
  消えた行より上のレールと機関車は 1 段下がる。機関車のいる行とそれより上、および機関車が盤面に入る前は消えない。
- 出現位置が埋まったらゲームオーバー。

## 操作

| キー | 動作 |
| --- | --- |
| ← / → (A / D) | 移動 |
| Space | パネルを時計回りに 90° 回転 |
| ↓ (S) | ソフトドロップ |
| ↑ (W) | ハードドロップ |

## 構成

- `src-tauri/src/core/` — 純粋なゲームロジック (Rust)。UI/Tauri 非依存、カバレッジ 100% 維持。
- `src-tauri/src/commands.rs` — Tauri Command (`new_game` / `get_state` / `send_input` / `tick`)。
- `src/` — 描画と入力のみ (TypeScript / React / Canvas)。ロジックは持たない。

## 開発

```bash
npm install
npm run dev:app      # = npm run tauri dev
npm test             # Vitest
npm run test:coverage
npm run test:rust    # tarpaulin (core 100% 必須)
cargo test --manifest-path src-tauri/Cargo.toml
```
